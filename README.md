# cpp-algorithms

A C++17 implementation of classic data structures and algorithms.

## Requirements

- C++17
- CMake >= 3.16

## Build

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

## Test

```bash
./test_sort
```

## Algorithms

### Sorting

- Insertion Sort
- Selection Sort
- Bubble Sort
- Merge Sort
- Quick Sort
